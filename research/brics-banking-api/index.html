API credential handling

Public docs describe how approved developers create credentials; they do not disclose usable private keys. Store credentials in server-side secret managers, enforce least privilege, mTLS/OAuth where required, audit logs, test sandboxes and explicit transaction approval. Never place live keys in browser JavaScript or GitHub.
